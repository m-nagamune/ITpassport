# ITパスポート 学習ノート

1つのHTMLファイルで完結する、ITパスポート試験の学習アプリです。
CSS・JavaScript・問題データをすべて内蔵しており、**インストール不要・オフライン動作**します。

## 成果物

- `public/index.html` — **これ1つがアプリ本体**（約260KB）。ブラウザで開くだけで動きます。

## 主な機能

| 機能 | 内容 |
|---|---|
| 4択演習 | 分野別（ストラテジ／マネジメント／テクノロジ）＋ランダム。10問・20問・30問から選択 |
| **わからないボタン** | 4択を選ばずに「わからない」で記録。**正答率の分母には含め、正解にはしない**ので集計が濁らない |
| 過去問ベース | 公表過去問の論点を再構成した問題に「過去問ベース」ラベルを表示。絞り込み出題も可能 |
| 結果集計 | セッションごとの正答率・所要時間・解答一覧を保存し、履歴として一覧化。正解／誤答／わからないを区別表示 |
| 分析 | 分野別（3分野）／中分類／**小分類（システム監査など）**の正答率、正答率の推移グラフ、「わからない」件数 |
| ロードマップ | 受験日から逆算して学習日を算出。**分野別正答率が低いほど配分を増やす**よう自動編成 |
| 復習モード | 間違えた問題＋「わからない」問題を自動的に集めて出題（誤答ノート） |
| 模擬試験 | 本番形式60問・制限時間60分・時間切れで自動採点。「わからない」も使用可（戻って変更可） |
| 用語カード | 86枚のフラッシュカード。分野絞り込み・シャッフル・苦手登録 |
| 記録の保存 | localStorageに自動保存。中断時は「続きから再開」、JSONで書き出し／読み込みも可能 |
| 問題管理 | 自作問題の追加（**1問ずつ／まとめて貼り付け**）、組み込み問題の編集・非表示。中分類／小分類も指定可能 |

## 「わからない」ボタンの仕様

4択から当てずっぽうで選ぶと正答率が実力より高く出てしまい、弱点分析が狂います。そこで各問題に「わからない」を用意しました。

| 項目 | 挙動 |
|---|---|
| 記録内容 | `{pick:null, ok:false, unsure:true}` として保存（未解答） |
| 正答率 | **分母に含める**（10問中1問わからない→9問が分母ではなく10問が分母）。分子には入らない |
| 復習モード | 不正解と同じく復習対象に残る |
| 結果画面 | 「わからない（正解 ア）」と誤答と区別して表示。件数と解き直しボタンも個別に表示 |
| 履歴 | `正解数/問題数 (わからないN)` と表示 |
| 模擬試験 | 押せるが**ロックしない**（前の問題に戻って選び直せる）。解説は表示しない |
| キーボード | `E` または `?` |

## 問題を追加する（問題数は増やせます）

収録は132問（ストラテジ35／マネジメント40／テクノロジ57）です。自作問題は以下の2通りで追加でき、演習・模擬試験・復習のすべてに加わります。

1. **「問題演習」画面の下部** →「＋ 1問ずつ追加」または「まとめて追加（貼り付け）」
2. **「問題管理 > 問題管理」タブ** →「＋ 問題を追加」／「まとめて追加」

### まとめて追加（貼り付け形式）

1問を**空行**で区切り、次の順に書きます。

```
分野|中分類|小分類
問題文
ア．選択肢1
イ．選択肢2
ウ．選択肢3
エ．選択肢4
正解=ア
解説（任意）
```

- `分野` は `strategy`／`management`／`technology` のほか「ストラテジ」「マネジメント」「テクノロジ」「経営」「監査」などの日本語も解釈します
- `ア．` `イ.` `ウ、` など記号の揺れ、`正解＝ウ` の全角も吸収します
- JSON配列（`[{field, mid, sub, q, c:[4], a, e}]`）を貼り付け、またはJSONファイルを選択しても取り込めます
- 追加前に「N問を追加できます」とプレビューし、形式エラーの件数も表示します

## 使い方

1. `public/index.html` をブラウザで開く
2. 初回案内で「10問はじめる」→ 現在地を確認
3. 結果画面で分野別・小分類別の弱点を確認
4. 「学習ロードマップ」で今日のタスクを実行し、チェックを付ける
5. 誤答は「復習モード」で潰す。直前は「用語カード」で暗記
6. わからない問題は当てずっぽうで選ばず「わからない」を押す

### 初期設定（変更可能）

- 受験予定日：2026年11月12日
- 学習ペース：1日60分 × 週4日（火・木・土・日）
- 目標正答率：70%
→ 「問題管理 > 学習の設定」から変更できます。

## データ構成

- **保存先**：ブラウザの localStorage（キー `itp_notebook_v1`）
- **問題データ**：`{id, field, mid, sub, q, c[4], a, e, pt, p, y}`
  - `field`=分野、`mid`=中分類、`sub`=小分類（分析の最小単位）、`a`=正解の添字、`e`=解説、`pt`=暗記ポイント、`p`=過去問ベース
- **履歴**：`{id, ts, mode, field, count, correct, unsure, blank, rate, sec, answers[]}`
  - `answers[]` の各要素：`{qid, pick, ok, unsure, ts}`
- 収録問題：132問（ストラテジ35／マネジメント40／テクノロジ57）＋用語86枚

## 開発メモ

ソースは `parts/` に分割し、`build.sh` で単一HTMLに結合しています。

```
bash build.sh              # parts/* → public/index.html
node test/e2e.js           # 基本機能の動作検証（要 http://localhost:3000）
node test/e2e-ask2.js      # 「わからない」＋問題追加の検証（40チェック）
node test/verify-plan.js   # ロードマップの苦手分野ウェイト検証
```

## 注意

収録問題は出題範囲に沿って作成したサンプルです。「過去問ベース」も公表問題の論点を参考に再構成したもので、出題文そのものではありません。
受験前には IPA の公開問題・公式過去問題集で最終確認してください。
